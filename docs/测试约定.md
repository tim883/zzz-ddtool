# 测试与验收约定

更新：2026-10-13。测试用于发现可描述的错误；通过数不作为功能正确、游戏适配或交付完成的替代指标。开发入口见 [开发规范](./开发规范.md)。

## 1. 先说明可能错在哪里，再选测

每次改动说明受影响的行为、直接调用方和持久格式，再选择能发现这些错误的现有用例。已有有效断言优先复用；不为了编号或维持数量再造一份测试。

- 只移动 / 修改文档：检查本地链接、图片引用和被移动的输入路径；不影响程序或测试输入时，不跑 OCR、GUI 或业务全量。
- 纯判断、配置、存档：跑对应模块及消费该结果的关键回归，例子是号位 / 白名单 / 来源判断的具体输入与输出。
- 截图、识别、遍历、等待或标签：覆盖改变的分支及执行器调用点，保留误认、未知、超时、失败停止和不重复输入等相关边界；按需选用 `tests/fixtures/` 下的固定样本或输入替身。
- GUI 逻辑：用离屏组件和替身执行器检查编辑、保存、任务切换及控制状态。字体 / 窗口几何不作为识别或执行链的验收。
- 跨模块共享格式、广泛基础设施或正式发布：说明为什么原子集不足，再跑影响范围较广的回归；需要全量时明确范围和频率。全量不是每一步或每次改文档的默认要求。

相关测试通过后直接推进交付；只有新改动、失败或未解疑点才重复运行。失败后先重跑具体失败项，必要时扩大到它的调用方。不能因为漏列影响范围而漏测，也不因无关用例失败把小改造无限扩成全项目修复。

## 2. 用例必须能拒绝错误结果

- 断言来自独立的预期行为。不能把被测函数的输出再拿来生成它自己的 expected，或接受全部可能结果后声称决策正确。
- 替身用于隔离截图、输入、时钟、磁盘等外部边界；不把正在验证的核心分支替换成永远返回正确结果的函数。
- “没有报错”“不为 None”“耗时非负”只证明对应的狭窄性质；若要验证保存、判定或耗时，应断言具体内容、动作或模拟时钟差值。条件不满足就什么都不检查的用例应修订或删除。
- 检查断言质量时，可对具体可疑用例做一次内存中的错误替换，证明它会失败。不为所有测试增加常规反向测试，也不为文档整理追加测试。
- `tests/fixtures/` 下的固定测试样本是显式测试输入，缺失或无法加载必须失败。不能依赖可回收的 `log/` 或 `log_test/`——测试自身的日志落在 `log_test/`，只有固定测试样本才是不变输入，缺样本后跳过又宣称该功能已覆盖。
- 环境缺少选中用例所需的锁定依赖，应报告环境错误；运行依赖不是可选项，不通过 `importorskip` 把缺依赖伪装成验收完成。

过时、重复、只约束实现写法或失去可检验目标的用例可以改写或删除，记录被替代的行为覆盖。有效的安全边界、真实故障回归和独立正反例继续保留。

## 3. 现行用例、停用用例与真机边界

普通 pytest 默认排除 `window` 和 `legacy`：前者会创建真实桌面窗口，后者只验证停用功能的保留实现。当前已停用的头像识别用例标为 `legacy`，不进入当前功能的默认回归；确实修改该函数时再显式选择。

```powershell
# 示例：本次修改测试守卫 / 坐标逻辑，选择对应文件。
.\.venv\Scripts\python.exe -m pytest -q tests/test_conftest_guard.py tests/test_layout.py

# 修改停用头像函数时，显式验证该保留实现；仍不代表生产已装备跳过生效。
.\.venv\Scripts\python.exe -m pytest -q tests/test_equipped.py -m legacy
```

Qt 默认强制离屏，不在自动回归中抢桌面焦点；需要真实窗口时用 `ZZZ_DDTOOL_TEST_WINDOW=1` 显式放行，且须属于用户授权的具体验证目标。截图重放证明已有样本上的表现，输入替身证明调用及控制边界；已有样本不证明新样本识别可靠，也不等于真机点击、滚动或材料操作验收。

保留 `True / False / None` 的识别语义，未知不得当空位、未锁定或成功。稳定的游戏规则作为前提直接使用，不重复确认；已完成且本次不改的功能不补历史样本或重跑旧场景。

## 4. 报告范围和缺口

报告记录解释器与依赖可用性、实际命令 / 节点、通过 / 失败 / 跳过 / 未执行，以及验证对象和限制。没有跑的内容明确未覆盖；不把一个子集写成全项目通过，也不把 `find_spec` 找到空目录写成依赖可用。

在研改造先声明影响范围，并把必要验收行为映射到实际执行的节点；这些节点必须通过，skip / xfail / 缺项不算验收。无关失败单列且不宣称已解决，相关失败必须修复。旧方案与最新要求冲突时先同步版本和范围，不偷偷屏蔽测试。

改造过程与未完成事项维护在源码根同级的私有 `../dev-docs/`，不是公开回归的一部分。历史命令、测试数量和已取消的基准不自动成为下一轮工作要求。
