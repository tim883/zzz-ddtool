# 游戏规则（开发前提）

本文记录稳定的游戏前提，按 Gxx 编号给出**规则本身**与**它对工具实现的影响**。规则是执行前提，不代表对应功能已经实现或通过真机验收；位置、阈值与页面判据等技术细节见 [识别标定](技术/识别标定.md)、[页面识别](技术/页面识别.md)。

| 编号 | 游戏规则 | 对实现的影响 |
| --- | --- | --- |
| <a id="g01"></a>G01 | 驱动盘状态筛选按钮呈灰色且不可点击，表示当前筛选条件下不存在该类型的盘；“其他”指未装备、未锁定、未弃置 | 灰色是无候选的正常状态，不反复点击、不当作工具失败；状态识别不清属于未知，不能与无候选混同 |
| <a id="g02"></a>G02 | 状态筛选取并集：同一驱动盘可同时处于锁定与装备状态。只选“已装备”时，同时锁定的装备盘仍会出现 | 游戏的允许状态集合不能简单等于跳过开关的反集；混合跳过配置仍需补充校验 |
| <a id="g03"></a>G03 | 仓库常规视口为 9 列 × 4 行；点击第 2 / 3 行不会引起自动滚动，首 / 末行可能使焦点自动居中 | 普通批次只点中间稳定行，首 / 末行按位置规则延期处理；不能沿用自动滚动之前的坐标，否则会阶梯漏盘 |
| <a id="g04"></a>G04 | 任务列表按等级降序排列，15 级在前、0 级在后。强化升级后当前盘按新等级前移，视口可能跟随；其他盘相对顺序不变，同等级的具体插入点不必预测 | 保留未解决进度与原视口，不能拿升级盘的当前焦点当作下一盘的位置。前缀模型依赖等级降序与连续处理，不能越过未知候选。恢复与重扫口径见 [识别标定](技术/识别标定.md) |
| <a id="g05"></a>G05 | 驱动盘 → 音擎仓库 → 驱动盘后回到列表顶部，且号位、套装筛选与等级降序保留；退出到主页再进会丢失筛选 | 切页可作为置顶恢复路径；不能用额外 Esc 回主页来恢复；滚动行数需本机标定 |
| <a id="g06"></a>G06 | 在会排除最终标签的状态筛选下，普通打标后该盘暂不退出列表；来回切仓库页，或另一盘实际强化后返回，会刷新并应用累计变化。仍命中其他已选状态的盘不退出 | 现有实现不支持成员退出：单任务内以已确认总数为准，数量或可见格位集合变化即停止，不预先扣减、不重复扣减。普通打标继续使用当前显示列表。仅查看而未强化是否刷新、面板开关是否刷新尚不确定，不自行扩大触发点 |
| <a id="g07"></a>G07 | 已锁定的驱动盘直接按 R 会弹出确认弹窗；先按 T 解锁，再按 R 可绕过该弹窗 | 普通弃置与强化后弃置共用 T 解锁 → 快速确认 → R 弃置 → 快速确认；读数不清不补按，未确认解锁不发 R，暂停恢复不重发。弃置标记开关关闭时只停发 R，锁定盘仍先按 T 解锁；锁定标记（save）开关关闭不影响弃置前的解锁。该链路只有离线覆盖，真机未覆盖 |
| <a id="g08"></a>G08 | S 级驱动盘最高 +15，档位为 0 / 3 / 6 / 9 / 12 / 15；每 +3 补一条新副词条或强化已有词条；初始为 3 或 4 条副词条 | 每档重新判断，等级、稀有度与标签状态按实际页面读取。稀有度由面板等级上限推出（15 = S、12 = A、9 = B）；确认非 S 固定跳过、没有开关，上限读不出按不跳过处理，非 S 盘仍会被点开并计 1 件处理。非 S 盘不进强化页，A / B 盘到自己上限（12 / 9）的停链路径不可达，12 / 9 两个上限值本身仍缺真机样本。仓库格位上的稀有度小牌不读，判据见 [识别标定](技术/识别标定.md) |
| <a id="g10"></a>G10 | 套装筛选弹窗中，0 件、灰色带锁图标的套装仍可正常点击；这与 G01 的驱动盘状态按钮不同 | 按请求逐项选择全部套装，不按亮度或件数拒绝点击，也不删除路径目标；点击前只核对名称身份、不判勾选状态，点击后不校验勾选外观，“0 件套装是否真被选中”不经工具校验 |

游戏版本更新或实测与本表冲突时，按编号记录具体条件与新证据后修订。

状态筛选的扩展设计（含动态列表与延迟退出）尚未实施，不属于现有功能；当前程序已有的号位、套装与主副属性筛选不受影响。
