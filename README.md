# zzz-ddtool

绝区零驱动盘强化辅助：本地截图、OCR、按任务规则逐档强化或打弃置标签。**不分解**，不读游戏内存、不修改游戏文件、不抓包。

## 快速开始

1. 到 [发行版](https://github.com/tim883/zzz-ddtool/releases/latest) 下载程序包 zip（`zzz-ddtool-v<版本>.zip`）。
2. 解压到任意目录 —— 解压后根目录里直接就是 `zzz-ddtool.exe`。
3. 双击 `zzz-ddtool.exe`。**不需要安装 Python。**

之后有新版本在界面里点「检查更新」即可，不用重新下载解压。更新会直接替换程序目录，替换期间不要强制结束进程，**没有回滚**。

环境：Windows 10 / 11；游戏窗口化 16:9、客户区 1920×1080（强烈建议 1080p）、系统缩放 100%；工具输入需要相应权限。客户端配置、运行和停止方式见 [任务管理器使用说明](docs/使用/任务管理器使用说明.md)。

## 从源码运行（开发）

开发使用 Python **3.13.5** 和项目 `.venv`；环境安装、命令行与输出路径见 [开发与运行](docs/技术/开发与运行.md)。已有环境时，从仓库根启动源码窗口：

```powershell
.\.venv\Scripts\python.exe -m zzz_ddtool
```
