# zzz-ddtool

绝区零驱动盘强化辅助：本地截图、OCR、按任务规则逐档强化或打弃置标签。**不分解**，不读游戏内存、不修改游戏文件、不抓包。

## 快速开始

开发使用 Python **3.13.5** 和项目 `.venv`；完整环境安装、命令行与输出路径见 [开发与运行](手册/技术/开发与运行.md)。已有环境时，从仓库根启动源码窗口：

```powershell
.\.venv\Scripts\python.exe -m zzz_ddtool
```

游戏窗口化 16:9，系统缩放 100%；工具输入需要相应权限。客户端配置、运行和停止方式见 [任务管理器使用说明](手册/使用/任务管理器使用说明.md)。
