# 游戏规则（开发前提）

更新：2026-10-08。本文让接手的工程师 / agent 不依赖聊天记录理解游戏。**标为“用户已确认”的规则直接使用，不反复要求用户确认；规则确认不等于本工具已经实现并通过真机验收。** 图像例子由 [参考图库](参考图/索引.md) 链接，具体改造接口以对应 spec 为准。

| 编号 | 已确认的游戏规则与来源 | 对实现的影响 |
| --- | --- | --- |
| G01 | **用户已确认**：驱动盘状态按钮灰色且不可点击，原因是当前筛选条件下不存在该类型的盘；“其他”指未装备、未锁定、未弃置 | 这是正常无候选状态，不反复点击，不当作工具失败；状态读不清仍属于未知，不能混同无候选 |
| G02 | **用户已确认**：状态筛选是并集，同一盘可同时锁定与装备。只选“已装备”，同时锁定的装备盘仍出现 | 游戏的允许状态集合不能简单等于跳过开关的反集；混合跳过配置需可靠补充校验。参见 [筛选图说明](参考图/驱动盘筛选/说明.md) |
| G03 | **用户已确认**：仓库常规视口为 9 列 × 4 行；第 2 / 3 行点击不会引起自动滚动，首 / 末行可能使焦点自动居中 | 普通批次使用中间稳定行，端点按位置规则处理；不能沿用自动滚动之前的坐标导致阶梯漏盘 |
| G04 | **用户已确认**：任务按等级降序，15 级在前、0 级在后。强化升级后当前盘按新等级前移，视口可能跟随；其他盘相对顺序不变，同等级具体插入点不必预测 | 保留未解决进度与原视口，不能拿升级盘的当前焦点当下一盘位置。前缀模型依赖等级降序和连续处理，不能越过未知候选 |
| G05 | **用户已确认**：驱动盘 → 音擎仓库 → 驱动盘后回到顶部，号位、套装筛选与等级降序保留；退出主页再进会丢失筛选 | 切页可作为置顶恢复路径；不能靠额外 Esc 回主页恢复；滚动行数需本机标定。无需再次询问筛选是否保留 |
| G06 | **用户已确认**：在会排除最终标签的状态筛选下，普通打标后盘暂不退出；来回切仓库页或另一盘实际强化后返回会刷新并应用累计变化。仍命中其他已选状态的盘不退出 | 普通打标继续使用当前显示列表；在真正刷新点更新累计退出与进度，不预先扣减、不重复扣减。仅查看而未强化是否刷新、面板开关是否刷新未确定，不自行扩大触发点 |
| G07 | **用户已确认（记录在状态筛选 spec，2026-10-09 要求实施）**：已锁定盘直接 R 会有确认弹窗，先 T 解锁后 R 可绕过 | 普通/强化后弃置共用 T 解锁→快速确认→R 弃置→快速确认；读不清不补按，未确认解锁不 R，暂停恢复不重发。discard 关闭时两键都不发，save 关闭不影响弃置前解锁。已实现，真机链路尚未覆盖 |
| G08 | 已有游戏机制约定：S 盘最高 +15，初始 3 或 4 条副词条，每 +3 补新词条或强化已有词条 | 每档重新判断；等级、稀有度、状态读取适配实际页面。当前代码按上限 15 / 12 / 9 推 S / A / B，但 A / B 上限样本仍是对应实现的证据缺口，不将它们列作本表已确认真机事实。非 S 盘固定跳过、无开关（2026-10-12）；不再进强化页，A/B 到自己上限（12 / 9）的停链路径不可达，上限 12 / 9 本身仍缺真机样本 |
| G10 | **用户已确认（2026-10-08）**：套装筛选弹窗中，0 件、灰色带锁图标的套装仍可以正常点击；这与 G01 的驱动盘状态按钮不同 | 按请求逐项选择全部套装，不通过亮度/零件数拒绝点击，不删除路径目标；实际选中仍须验证 |

确认来源为此前已记录的用户游戏操作观察及本轮对灰色按钮的明确说明；图片用于展示对应外观，不能宣称单张图证明动态规则。后续游戏版本或实测出现冲突时注明具体规则编号、条件与新证据，再讨论修订。
