# 手册索引

本目录在 **git 仓库内**（`zzz-ddtool/`），不在外面一层工作区。

运行时截图、日志仍会本地留着，但在 `out/`，不进 git：

| 本地目录 | 用途 |
|----------|------|
| `out/captures/` | 每次截到的游戏图，最多 40 张 / 200MB |
| `out/logs/` | `ddtool.log`，最多 15 个文件 / 16MB |
| `src/zzz_ddtool/assets/templates/` | 程序认页时真正加载的图标 |
| `手册/素材/` | 同一批图标，中文文件名，给人核对 |
| `手册/样张/` | 已确认的整页截图 |

## 文档

| 编号 | 手册 | 说明 |
|------|------|------|
| 01 | [页面识别](./页面识别.md) | **安全底线**。每页用哪些图标认，认不上不准点 |
| 02 | [运行限制与筛选](./运行限制与筛选.md) | 处理上限、游戏筛选（重置后套用、Esc 退出）、已装备头像不弃、套装图标兜底 |

跑之前先确认：游戏窗口化 16:9、系统缩放 100%、工具以管理员权限运行（否则点不到游戏窗口）。

用户手册管「怎么用、什么条件能跑」；技术细节（标定坐标、踩坑根因）在
[doc/README.md](../doc/README.md)，开发排查看那边。
