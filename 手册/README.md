# 手册索引

本目录在 **git 仓库内**（`zzz-ddtool/`），不在外面一层工作区。

运行时截图、日志本地留着，都在 `log/`（第一层就叫 log），不进 git：

| 本地目录 | 用途 |
|----------|------|
| `log/text/ddtool.log` | **文本日志**，格式「页面 · 动作 → 结果」 |
| `log/captures/<本轮时间戳>/` | **图片日志**，文件名前缀是步骤号，和文本日志对应 |
| `src/zzz_ddtool/assets/templates/` | 程序认页时真正加载的图标 |
| `手册/素材/` | 同一批图标，中文文件名，给人核对 |
| `手册/样张/` | 已确认的整页截图 |

**跑出问题先看日志**：找 `[错误]` 那行 → 看行首步骤号（如 `0007`）→ 去
`log/captures/<时间戳>/0007-*.png` 看当时屏幕。详细排查步骤在
[doc/日志与截图.md](../doc/日志与截图.md)。

**要复现问题**：窗口顶部「日志设置」把级别调到「详细」再跑一遍。
截图始终全量保存，不随级别变化——级别只管日志写多少。
