# 手册索引

本目录在 **git 仓库内**（`zzz-ddtool/`），不在外面一层工作区。

运行时截图、日志仍会本地留着，但在 `out/`，不进 git：

| 本地目录 | 用途 |
|----------|------|
| `out/captures/` | 每次截到的游戏图，最多 40 张 / 200MB |
| `out/logs/` | `ddtool.log`，最多 15 个文件 / 16MB |
| `src/zzz_ddtool/assets/templates/` | 程序认页时真正加载的图标 |
| `手册/素材/` | 同一批图标，中文文件名，给人核对 |
| `手册/样张/` | 已确认的整页截图 |
