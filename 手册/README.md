# 手册索引

本目录在 **git 仓库内**（`zzz-ddtool/`），不在外面一层工作区。

运行时截图、日志仍会本地留着，但在 `out/`，不进 git：

| 本地目录 | 用途 |
|----------|------|
| `out/captures/<本轮时间戳>/` | 出问题时截的图，文件名前缀是步骤号，和日志对应 |
| `out/logs/ddtool.log` | 运行日志，格式「页面 · 动作 → 结果」 |
| `src/zzz_ddtool/assets/templates/` | 程序认页时真正加载的图标 |
| `手册/素材/` | 同一批图标，中文文件名，给人核对 |
| `手册/样张/` | 已确认的整页截图 |

**跑出问题先看日志**：找 `[错误]` 那行 → 看行首步骤号（如 `0007`）→ 去
`out/captures/<时间戳>/0007-*.png` 看当时屏幕。详细排查步骤在
[doc/日志与截图.md](../doc/日志与截图.md)。

想看工具每一步怎么走的，加 `--log-level debug`，每一步都会截图
（图多，排查完记得调回默认）。
