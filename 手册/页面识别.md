# 01 页面识别（安全底线）

认页靠 **图标模板**，不靠 OCR 读字。  
程序在规定矩形里做归一化相关（NCC），**这一页列出的图标必须全部过线**，才算在这一页。有一个不过就停，不准继续点。

坐标按窗口客户区 **1920×1080**。别的分辨率会按比例缩放。

程序加载：`src/zzz_ddtool/assets/templates/`  
下面配图是同一批文件，方便你对：`手册/素材/`

整页样张：`手册/样张/`

## 5. 对不上怎么办

日志会写每个图标的分数，例如 `快捷轮盘=0.41/0.85`。  
对不上就中断，**不要猜着点**。游戏改 UI 后，用新的整页截图重裁 `素材/` 和 `assets/templates/` 里同一批图。

当前 **不点**：强化、弃置、拆解、回收。认页只用这些按钮当路标。
