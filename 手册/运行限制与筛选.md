# 02 运行限制、游戏筛选、已装备

## 1. 本次最多处理多少盘

配置：`run.max_discs`（默认 100，至少 1）。  
窗口硬过滤里「本次最多处理 N 个盘子」。

每看一张盘（含跳过）算 1。到上限停，不继续点强化/弃置。方便试跑。

## 2. 进驱动盘后的筛选顺序

能按键就按键，不扫关闭按钮。

1. 点左下筛选漏斗（图一）
2. 点「重置」（先清空游戏里上次留下的条件）
3. 窗口里选套装（弹窗搜索+图）。**部位 1–6 单选**，右侧卡片和左侧权重是这一号的策略，换号会换一套。1–3 主词条固定不选；4/5/6 只出游戏里这个号能出的主词条。已选主词条不会出现在右侧副词条里。
4. **Esc 关掉筛选面板**，回到驱动盘列表，再开始逐张处理

关筛选用 Esc，比 OCR/找叉再点快，也不依赖关按钮模板。

漏斗点击：1920×1080 约 **(166, 906)**（白圈）。(224, 930) 是拆解蓝标，不能点。  
重置：你给的筛选图按 1.875 倍换算，约 (1301, 1033)。部位坐标先按右栏估算，进 1920 筛选页后再对一次。

预设：

```yaml
game_filter:
  sets: ["折枝剑歌"]
  slots: [1, 4]
  mainstats: ["暴击伤害"]
```

空列表 = 重置后不再加条件（游戏里等于不过滤）。

## 3. 格子右上头像 = 已装备

见图四：格子右上角圆形角色头像。  
判定后 `disc.equipped = True`。硬过滤「跳过已装备」默认开，**不标弃置**。

素材：`手册/素材/已装备-头像格.png`、`手册/素材/筛选-漏斗.png`。
