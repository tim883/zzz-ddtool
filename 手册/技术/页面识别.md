# 01 页面识别（安全底线）

更新：2026-10-10。本文区分严格模板校验、导航分类、弹层识别与就绪等待，描述当前代码的实际边界。

`screen.is_page(image, page)` 是**严格模板校验**：在规定矩形中做归一化相关（NCC），该页列出的图标必须全部过线才返回 `True`。驱动盘仓库到达、切页结果及位置恢复使用这一校验，失败按调用方的有限重试规则处理。

`screen.classify_image(image)` 先逐页调用严格校验；所有模板未命中时，仍可通过底部亮图标数量判为功能菜单，或通过大世界提示区白色像素比例判为大世界。启发式不返回音擎仓库或驱动盘仓库，不能等同于所有模板已通过。详细日志会区分“模板命中”和“启发式兜底”。

当前 `nav.goto_warehouse` 在分类为菜单时允许点击仓库入口；分类为大世界时允许 Esc 打开菜单；未知页面允许保存现场后有限次 Esc 剥离残留弹层。导航最多 8 轮，未知分支受 3 次 Esc 的容错计数限制，计数在大世界分支重置；只有严格确认驱动盘仓库才返回成功。切驱动盘页签的有限重试同样以严格仓库校验收尾。这里是导航容错范围，不是任意页面都能继续点击的规则。

弹层另行识别：`is_disc_modal` 检查关闭图标模板；`is_disc_preview` 读取固定区域的等级文字 OCR。强化链中的抓图关闭自动 Esc，按已识别的弹层逐层返回仓库；其重试与失败传播见 [截图与坐标](截图与坐标.md)。

坐标按窗口客户区 **1920×1080**。别的分辨率会按比例缩放。

## 5. 对不上怎么办

日志会写每个图标的分数，例如 `快捷轮盘=0.41/0.85`。  
严格仓库校验在有限重试后仍对不上，或导航超出上述容错范围时中断；不能用菜单/大世界的启发式结果替代仓库验证。游戏改 UI 后，用新的整页截图更新参考图库中的说明裁剪及 `assets/templates/` 中适用运行模板。

**认页层不执行**强化、弃置、拆解或回收，只将按钮作为路标；工具执行层仍按任务规则强化与打标签，始终不分解。

## 6. 就绪等待（扫描提速，2026-10-10）

认页层回答“现在在哪一页”；**就绪等待**回答“这一步的目标画面什么时候真的到位”。两者分开：
等待不靠页模板，而是各 kind 自己的**目标证据**在连续帧上稳定。

代码：`src/zzz_ddtool/readiness.py`（策略、稳定判定与下限计算）+ `runner.py::_wait_ready`（构造 probe 并调用）。
稳定规则固定不可改：`poll_ms=50`、要求连续 **2 帧**（`stable_frames=2`）状态 key 相同，且已过该 kind 的下限。

六类 kind（`readiness.KINDS`，定序不可改）：

| kind | 目标证据（完成条件） |
|------|----------------------|
| `select_disc` | 仓库侧栏/详情弹层布局正确，且原目标格位可见、选中态成立，等级与全部可见词条完整可读 |
| `open_preview` | 预览/详情页就绪（与传入的 before 帧比较） |
| `open_upgrade` | 强化页就绪（等级条与强化页副属性区） |
| `material_ready` | 素材条出现并就位（消耗类，被动观测） |
| `upgrade_result` | 升级后实际等级达到期望等级 |
| `return_warehouse` | 已回到仓库页 |

默认下限 / 固定超时（`readiness._DEFAULT_BOUNDS`，单位 ms）；下限可由真机标定覆盖，超时不改：

| kind | 默认下限 | 超时 |
|------|---------:|-----:|
| `select_disc` | 500 | 3000 |
| `open_preview` | 900 | 5000 |
| `open_upgrade` | 1500 | 8000 |
| `material_ready` | 600 | 3000 |
| `upgrade_result` | 1500 | 8000 |
| `return_warehouse` | 600 | 3000 |

超时抛 `ReadinessTimeout`，调用方按任务错误处理；未标定的 kind 保留上表默认下限。
本次真机标定值与判据细节见 [识别标定](识别标定.md)。

材料返还按两帧证据中断当前升级结果等待，只确认一次，再从实际确认输入结束时刻建立第二次等待，不重发升级。2026-10-11 收尾修复把中断帧的代次、窗口/PID、尺寸、任务/位置及盘/升级输入绑定延伸到确认点击和聚焦的实际输入检查点；中途失效直接停止，不按旧截图坐标。正常复验只读绑定，不额外重做全窗 OCR。
