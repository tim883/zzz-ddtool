# 驱动盘详情：图片与规则

参考图：[详情弹层](./详情弹层.png)，1920×1080，原 `手册/样张/详情页.png`。可见 S 级 0 / 15、生命值主属性、三条副属性、R 弃置与 T 锁定图标、进入强化的箭头。采集日期 / 版本 / DPI 未记录。

这是独立的详情弹层，**不是仓库右侧选中盘摘要**；动作图标与词条位置不同。不要把弹层里缺少“解除锁定”文字，推广成仓库侧栏也没有提示。等级当前值和上限分别读取，不能将上限 15 当当前等级；副属性按名称 / 数值配对。

强化规则见 [G08](../../游戏规则.md)，页面路径与识别区域见 [识别标定](../../技术/识别标定.md)。`tests/test_ocr.py` 复用本图；已有功能不要求额外补图。本轮只整理、解释，不对新分支作真机通过声明。

两张 1920×1080 原图由 PrintWindow 截图无损复制；本样本未独立核验窗口 DPI。它们只证明旧问题，不证明修复已经真机通过。`save: true` 的收尾在退出强化页后、任何仓库分页恢复前核对盘面并锁定；未锁定只按一次 T，已锁定不再按，未知或不一致失败。实际新链路按 [Spec §15](../../../dev-docs/功能改造/仓库导航与状态筛选/筛选动作提速与套装路径回放-spec.md) 及其真机测试 Plan 验证。

`tests/test_kept_upgrade.py` 从两图读取等级 0/15；侧栏文字提示能读出初始锁定 False，15 级完整盘面图在当前侧栏提示判读中为 None。该未知不得自动改为 False，不拿它直接驱动 T；新收尾先退回侧栏再读标签。新链路 Esc 后同盘侧栏及 T 后原图仍待真机采集。
