# 功能菜单：图片与规则

参考图：[仓库入口](./仓库入口.png)，1920×1080，原 `手册/样张/功能页.png`；下方菜单可见“仓库”，上方有返回箭头。裁剪：[返回](./裁剪/返回.png)、[仓库入口](./裁剪/仓库入口.png)。两个裁剪与当前运行模板字节一致。

这是从大世界打开的功能菜单，不是仓库。菜单的返回箭头也出现在其他页面，不能仅凭箭头认仓库。导航进入仓库与强化后返回仓库是不同路径；连续 Esc 可能退出仓库到这里，不应把退出误判成列表处理完成。参见 [页面识别](../../技术/页面识别.md)、[G05](../../游戏规则.md)。

采集日期 / 版本 / DPI、裁剪原始帧未记录。本图讲解已有菜单入口；不为本轮规范整理重新验证导航。
