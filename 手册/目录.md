# 项目手册目录

> **仓库内的长期文档只维护这一套。开发先读 [开发规范](./开发规范.md)，理解游戏先读 [游戏规则](./游戏规则.md)，找图片先读 [参考图索引](参考图/索引.md)。** 不再并行维护 `doc/`、`screens/` 或散放在手册根目录的图片。

| 用途 | 入口 |
| --- | --- |
| Agent / 工程师开发规范 | [开发规范](./开发规范.md)：目录、图与规则说明、改造交付和环境 |
| 测试与验收 | [测试约定](./测试约定.md)：影响范围选测、断言质量、停用用例与真机边界 |
| 游戏规则 | [游戏规则](./游戏规则.md)：用户已确认的前提及对工具的影响 |
| 客户端使用 | [任务管理器](./使用/任务管理器使用说明.md)、[运行限制与筛选](./使用/运行限制与筛选.md) |
| 开发环境与运行 | [开发与运行](./技术/开发与运行.md)：安装、源码启动、CLI、日志与打包入口 |
| 技术实现 | [页面识别](./技术/页面识别.md)、[识别标定](./技术/识别标定.md)、[截图与坐标](./技术/截图与坐标.md)、[输入与等待](./技术/输入与等待.md) |
| 排查当次运行 | [日志与截图](./技术/日志与截图.md)；运行图位于当前轮次目录 `log/<时间戳编号>/captures/` |
| 开发参考图库 | [参考图索引](参考图/索引.md)；每个页面的 `说明.md` 解释对应图片与游戏规则 |
| 打包与发布 | [打包与发布](./技术/打包与发布.md) |
| 当前改造与待办 | 仓库内 [dev-docs](../dev-docs/README.md)，维护在研 / 搁置主题及剩余事项 |
| 已实施变更与历史证据 | [历史变更索引](../dev-docs/history/README.md)，按主题归档方案、审查和过程记录 |

`使用/` 给用户说明现有功能，`技术/` 描述源码实现，`参考图/` 保存开发对照和规则解释。需要给用户配图时直接引用参考图库，避免复制维护两份。源码真正加载的模板仍在 `src/zzz_ddtool/assets/templates/`，回归专用输入仍在 `tests/fixtures/`。

规则已确认、代码已实现、离线测试通过、真机操作通过分别记录。不要要求用户为已记录的游戏前提反复确认，也不要将未实施 spec 写进使用说明冒充现有功能。
