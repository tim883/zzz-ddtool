# 截图与坐标

## 坐标体系

所有 UI/网格坐标常量在 `src/zzz_ddtool/layout.py`，按 **1920×1080 设计坐标**写死。

- `scale_point(x,y,w,h)` = `(x*w/1920, y*h/1080)`
- `scale_rect(...)` 同理
- `ocr.py::read_rect` 内部自动 `scale_rect`（传设计坐标，内部按真实分辨率缩放）
- 点击 `wininput.click_client` 用客户区坐标 + `ClientToScreen` 转屏幕坐标

对齐 OneDragon `pc_game_window.py` 的 `get_scaled_game_pos`：标准坐标 × (实际宽/1920, 实际高/1080)。

## 截图窗口选择（踩坑）

`capture.py`：
- `find_game_hwnd()`：优先匹配 `exe == ZenlessZoneZero.exe`，标题兜底（含"绝区零"/"ZenlessZoneZero"）
- `_print_window()`：`PrintWindow(hwnd, PW_CLIENTONLY|PW_RENDERFULLCONTENT)` 截客户区
- 黑图时降级 `_grab_screen_region`（Qt grabWindow）

**坑（2026-09-06）**：游戏窗口**最小化**时 `GetClientRect` 返回 0×0，旧逻辑 `if width<64: skip` 会把游戏窗口跳过，fallback 到标题匹配，误中 **OneDragon 的 python 窗口**（标题"绝区零 一条龙 01"，客户区 1140×760），截图全错、坐标全偏。

**修复**：
1. exe 匹配不因最小化跳过（最小化也记录 hwnd）
2. 标题兜底排除 `exe 含 python`（OneDragon 窗口）
3. `grab_game_image` 截图前 `_restore_window`：`IsIconic` 则 `ShowWindow(SW_RESTORE)` + `SetForegroundWindow`

**排查截图分辨率异常，第一步查游戏窗口是否最小化 / 被切走。**

## 悬浮日志窗口（overlay）

`overlay.py`：纯 ctypes 的 Win32 分层窗口（参考 March7thAssistant debug_overlay）。

- 类名 `ZZZDDToolOverlay`，标题空，`WS_EX_LAYERED|TRANSPARENT|TOOLWINDOW|NOACTIVATE|TOPMOST`
- 品红 `RGB(255,0,255)` 色键透明，只显示白字
- 消息循环跑在 `daemon=True` 线程；**进程退出 → daemon 线程终止 → 窗口随进程销毁**，所以结束任务就消失（正常，非 bug）

## 升级流程（判断在强化页）

页面路径：`仓库页 → 点格子 → 详情页 → 点「查看/强化」→ 缩放页 → 点「》」→ 强化页`。

**判断、升级都在强化页**（左边卡片有副属性，且等级是单独数字读得准）；**弃置（R）在详情页**（强化页没有 R 按钮）。

`runner.py` 把旧 `_do_upgrade` 拆成 4 个方法：
- `_enter_upgrade_page(hwnd)`：详情页点「查看/强化」→ 缩放页点「》」→ 强化页（检测「阶段添加」出现即成功）
- `_upgrade_once(hwnd)`：强化页点「阶段添加」→「升级」，升一阶
- `_upgrade_loop(...)`：强化页循环——`parse_disc_upgrade_page` 判断 → 判升级就 `_upgrade_once` 原地循环；判弃置 Esc 回详情页按 R；判跳过 Esc 回网格
- `_discard_from_upgrade(hwnd)`：弃置——Esc 两次回详情页 → 按 R → Esc 回网格

**主循环 UPGRADE 分支**：详情页 `decide` 判 UPGRADE → `_enter_upgrade_page` 进强化页 → `_upgrade_loop` 循环升级/弃置 → 回网格后 `rescan` 重扫（升级改变等级排序 + 弃置的要跳过）。

**页面层级（Esc 次数）**：强化页 →(Esc)→ 缩放页 →(Esc)→ 详情页 →(Esc)→ 网格。弃置时要 Esc **两次**才回到详情页按 R（原来 Esc 一次落在缩放页上，按 R 无效）。

**踩坑（2026-09-06）**：旧实现升级完直接 `_esc_back_to_grid` 回网格 + 全量重扫，把强化页当「进一下就退」的跳板，每升一阶都重扫整页。老大纠偏：升级完留强化页原地判断，符合继续升、不符合才 Esc 回详情页弃置。
