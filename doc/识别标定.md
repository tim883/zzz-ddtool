# 识别标定

所有标定基于 **1920×1080** 标准分辨率。格子网格 `GRID_ORIGIN=(166,267)`、`GRID_STEP=(135,175)`、9 列 × 4 行，格子中心 `(cx,cy) = (166+c*135, 267+r*175)`。

## 弃置标（右下角红色小牌）

**位置**：格子**右下角**，相对格子中心偏移约 `(dx=+34, dy=+28)`，约 16×16。

**颜色**：纯红 `RGB(203,0,0)`（部分边缘 157~196，G、B 恒为 0）。

**判定**（`equipped.py::tile_has_discard_badge`）：
- 扫描区：`cx+20..cx+50, cy+15..cy+45`
- 条件：`R>150 且 G<30 且 B<30` 的像素数 ≥ 50

**实测分布**（`out/captures/verify-discard.png`）：有标格子红色像素 245~266，无标 0，双峰干净。

**踩坑记录**：曾经误标为「格子左半」和「右上角」，全未命中。弃置标就是右下角红牌，别无他处。

## 已装备头像（右上角彩色圆形）

`tile_has_portrait(image, left, top, right, bottom)`：格子右上角区域（宽 58% 起、高 2%~40%）采样，彩色像素占比 ≥ 12% 判为已装备头像。

## 等级标签（格子中心下方）

`GRID_LABEL_DY=87`：等级标签中心在格子中心**下方 87px**。OCR 扫标签定位格子时，`格子中心 cy = 标签中心 y - 87`。

等级文本形如 `等级15`（满级）、`等级0`~`等级14`。满级 `>=15` 在扫描阶段跳过不点（`skip_max_level`）。

## 页面路径与副属性坐标（2026-09-06 OCR 实测老大截图标定）

页面路径：`仓库页 → 点格子 → 详情页 → 点「查看/强化」→ 缩放页 → 点「》」→ 强化页`。

判断、升级都在**强化页**；弃置（R）在**详情页**。两页副属性位置不同：

| 页面 | 副属性区 (设计1920×1080) | 等级 | 备注 |
|------|--------------------------|------|------|
| 详情页 | x1174-1772, y400-483 | `等级03`(1213,205)+`15`(1316,197) | R(960,271) T(1043,271) |
| 强化页 | x883-1692, y419-501 | 当前等级数字 y539 附近 | 阶段添加(1283,858) 升级(1526,859) |

- 强化页副属性整体比详情页**左移约 300px**，判断移到强化页必须用强化页坐标。
- 强化页「阶段添加」「升级」按钮与详情页副属性区都在强化页弹层内，升级完原地再判断，无需退回网格。

## 副属性两列布局配对（2026-09-06 重写）

副属性是**两列布局**：`名字 数值 | 名字 数值`（第一列名字 x878/1174 起，第二列名字 x1298/1495 起）。

旧的单一 `split_x` 切分（名字在左、数值在右）会把第二列名字误当数值、第一列数值误当名字 → 配对全乱。

正确做法（`ocr.py::_pair_substat_lines`）：
- **名字** = 含非数字字符（中文）；**数值** = 纯数字（可含 `%`）
- 按 y 聚类成行，行内按 x 排序后「名字 → 右侧最近的数值」相邻配对

## 详情页坐标曾标错页面（根因）

`layout.py` 旧的 `SUB_STATS=(1415,558,1840,775)` / `DISC_LEVEL` / `MAIN_STAT` 标的是**仓库页右侧选中盘摘要面板**的坐标（偏下约 150px），而 `parse_disc` 是在**详情页**（点开盘后）读副属性 → 一直读不到副属性，`parse_disc` 返回 None，决策输入是空的。

已按详情页 OCR 实测重标（`layout.py`）：
- `DISC_LEVEL=(1180,190,1310,250)`（等级，避开右侧「15」上限数字）
- `MAIN_STAT=(1150,295,1470,345)`
- `SUB_STATS=(1160,390,1790,495)`
- 强化页：`UPGRADE_LEVEL=(940,525,1100,580)`、`UPGRADE_SUB_STATS=(883,419,1692,501)`、`UPGRADE_SUB_SPLIT_X=1250`（已不用）

## 等级读取：强化页比详情页准

- 详情页等级是「等级03」文字，OCR 常把 03 误读成 00 / 8，且旁边有「15」上限数字干扰 → `read_level` 不稳定。
- 强化页等级是**单独数字**（如 `3`），OCR 读得准。判断放强化页，等级可靠。
